order_new_negative_price.bin
============================

A negative limit price. The field is signed on the wire, and a decoder that reads it unsigned returns a colossal positive number rather than an error.

Generated by schema/goldens.py. This dump exists so the vector can be
checked against the byte table in docs/WIRE.md by eye rather than by
running the code that is supposed to be under test.

No packetHeader: this is an order-path vector, and an order-path
message travels one per shared-memory ring slot rather than batched
into a datagram. See docs/ORDER-PATH.md.
